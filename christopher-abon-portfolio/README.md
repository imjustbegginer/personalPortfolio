# Christopher Abon — Personal Portfolio

A responsive, dark minimalist personal portfolio built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — layout, colors, responsive styles, and animations
- `script.js` — mobile navigation and scroll reveal effects
- `assets/` — place your profile photo or other images here

## Preview locally

Open `index.html` in your browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository, for example `christopher-abon-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository's root.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then click **Save**.
7. Wait for GitHub Pages to publish your site. Your website address will appear in the Pages section.

## Customize

- Update your details and page text in `index.html`.
- Change colors and styling in `style.css` (the main accent color is `--accent` near the top).
- Add a profile image to `assets/` and update the HTML where you want it displayed.
